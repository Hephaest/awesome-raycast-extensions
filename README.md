# Awesome Raycast Extensions
A collection of custom extensions designed to streamline your working workflows with Raycast, especially when you're using Jira and GitHub.

> **Disclaimer:**
>
> The Jira and GitHub extensions were created by other developers. Full credit goes to the original authors for their foundational work.
>
> My contributions focus on adding new features and optimizing the extensions for better performance and user experience.

## 🧩 Extensions
### Jira
Browse your saved Jira filters, with each issue's parent shown on the list. See [jira/README.md](jira/README.md).

### GitHub
See the pull requests waiting on you from the menu bar, and search your review requests. See [github/README.md](github/README.md).

### Zadig
Search your Zadig workflow runs and environments, and manage sub-environments. See [zadig/README.md](zadig/README.md).

### English Dictionary
Look up English words in Wiktionary, Collins and Merriam-Webster, and hear them pronounced. See [english-dictionary/README.md](english-dictionary/README.md).

## 🛠 Installation
1. Clone this repository.
2. In Raycast, run **Import Extension** and select an extension folder, such as `zadig`, not the repository root.
3. When Raycast asks, fill in the extension's required preferences, such as an access token.
